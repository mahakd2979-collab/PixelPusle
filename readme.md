# LensHop

LensHop is a sleek, modern image search web application built entirely from scratch using vanilla HTML, CSS, and JavaScript. The app provides a fluid interface designed to let users explore high-definition photography effortlessly.

## Design Decisions
* **Color Palette Choice:** I opted for a dark theme built around charcoal slate `#12181f` and vibrant teal accents `#2dd4bf` to create a stark visual separation from the purple-hued PixelPulse reference project.
* **Suggestion Chips Layout:** I implemented a quick-pick suggestion row centered below the form inputs to offer immediate interactive ideas, minimizing user keyboard input requirements.
